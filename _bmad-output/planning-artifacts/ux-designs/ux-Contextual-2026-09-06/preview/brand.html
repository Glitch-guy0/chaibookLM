Accent Semantics

Visual Language Rules

  1. Zero-blur offset shadows carry depth; keep borders 2px ink.
  2. Citation cyan appears only on verification affordances (pills, highlights, anchors).
  3. Space Mono for headings/badges/metrics; Inter for body text.
  4. All buttons follow the same elevation flow: standard 4px → hover 6px → pressed translate.
  5. Hard 2px ink borders + sharp 2–4px radii everywhere.
