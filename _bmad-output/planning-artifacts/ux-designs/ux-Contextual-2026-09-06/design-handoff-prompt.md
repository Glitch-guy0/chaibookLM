```markdown
=== COPY-PASTE PROMPT BELOW ===

You are an elite Staff UI/UX Designer and Frontend Design Technologist specializing in modern, tactile Neo-Brutalist design systems.

Design a comprehensive design system and responsive UI mockups for "Contextual" — a high-velocity, personal research workspace inspired by Google NotebookLM, featuring multi-modal source ingestion (PDF, Web, YouTube, Transcripts, Text) and Deep Original View citation verification.

### 1. Brand Identity & Visual Aesthetic: Upgraded Neo-Brutalism
- **Core Personality:** High-energy, crisp, tactile, utilitarian, and fast. Not messy or nostalgic brutalism, but precision-engineered modern neo-brutalism with bold ink borders, solid offset drop shadows, sharp monospaced accents, and vibrant electric yellow and cyan highlights.
- **Color Palette (Light Mode):**
  - Brand Accent Yellow: `#FFE500` (Used for primary CTA buttons, active user message bubbles, and warning highlights)
  - Citation Cyan: `#00E5FF` (Strictly reserved for citation pills `[1]`, PDF bounding-box highlights, and quote anchors)
  - Deep Ink: `#111111` (Borders, high-contrast text, hard shadows)
  - Muted Ink: `#555555` (Secondary text, metadata, subtle borders)
  - Crisp Surface: `#FFFFFF` (Card backgrounds, workspace panes)
  - Canvas Background: `#F4F4F0` (Slightly warm off-white industrial canvas)
  - Destructive / Alert Red: `#FF3333` (Zero credit state, deletion warnings, error tags)
  - Success Green: `#00E575` (Ingestion ready, valid status)
- **Dark Mode Palette:**
  - Dark Canvas: `#0D0D0D`
  - Dark Surface: `#18181B`
  - Dark Border / Ink: `#FFFFFF` or `#E4E4E7`
  - Brand Dark Yellow: `#FACC15`
  - Citation Cyan Dark: `#22D3EE`
  - Muted Text Dark: `#A1A1AA`
- **Typography:**
  - Headings, Badges, Metrics, and Code: `Space Mono`, monospace, bold (`font-weight: 700`), uppercase for tags.
  - Body Text, Paragraphs, Chat Responses: `Inter`, sans-serif (`font-weight: 400, 500, 600`), clean and legible with generous line-height (`1.6`).
- **Shadows & Elevation (Zero Blur):**
  - Standard Card / Container: `box-shadow: 4px 4px 0px 0px #111111`
  - Elevated / Focus State: `box-shadow: 6px 6px 0px 0px #111111`
  - Slanted Button Shadow: `box-shadow: 6px -6px 0px 0px #111111` with `skewX(-12deg)` compensation
  - Pressed / Active State: `box-shadow: 0px 0px 0px 0px #111111; transform: translate(4px, 4px)`
- **Borders & Radii:**
  - Hard borders: `2px solid #111111` (or `#FFFFFF` in dark mode)
  - Corner radius: Sharp 2px to 4px (`rounded-sm`), avoiding bubbly circular radii (except for the 9999px credit badge pill).

---

### 2. Core Reusable Neo-Brutalist Components

1. **Slanted Action Button (`<NeoButton>`):**
   - Shape: `transform: skewX(-6deg)`, border `2px solid #111111`, background `#FFE500` (primary) or `#FFFFFF` (secondary).
   - Drop shadow: Solid offset `6px -6px 0 0 #111111`.
   - Hover state: Deepens skew to `skewX(-10deg)` with `translate(-2px, 2px)`.
   - Active / Pressed state: Skew resets to `skewX(0deg)`, shadow collapses to `0 0 0 0`.
   - Accessibility: When `prefers-reduced-motion` is active, skew stays at `0deg` and hover uses thick bottom border.
2. **Inline Citation Pill (`<CitationPill>`):**
   - Shape: Non-slanted rectangular pill, `padding: 2px 6px`, `border: 1.5px solid #111111`, `border-radius: 2px`.
   - Background: Bright Citation Cyan (`#00E5FF`).
   - Font: `Space Mono`, 11px, bold, black text. Numbers: `[1]`, `[2]`, `[3]`.
   - Micro-interaction: Hover displays source title + page/timestamp tooltip. Click triggers deep inspection in the Showcase pane.
3. **Source Card (`<SourceCard>`):**
   - 2px hard ink border, 4px solid shadow, type icon (PDF, Globe, YouTube, File, Subtitle).
   - Real-time ingestion status indicators:
     - `queued`: gray border, gray dot.
     - `indexing`: yellow border, CSS orbital neo-brutalist shadow spin animation.
     - `ready`: ink border, green pulse dot.
     - `failed`: red border, red dot + alert tooltip with retry button.
4. **Top-Bar Daily Credit Counter (`<CreditBadge>`):**
   - Monospace pill: `⚡ 8/10 credits`.
   - Yellow warning when ≤ 2 credits.
   - Red locked state at 0 credits (`🔒 0/10 credits`) disabling composer with an upgrade/reset notice.
5. **Auto-Deletion Warning Banner (`<ExpirationBanner>`):**
   - Full-width high-contrast yellow banner placed persistently above workspace:
     `"⏳ Auto-deletion Notice: This notebook will be auto-deleted tonight at 12:00 AM Asia/Kolkata (UTC+05:30)."`
6. **Honest Refusal Card & Web Search Fallback:**
   - When answers cannot be found in uploaded sources:
     - Card with warning border: *"The uploaded sources do not specify the requested information."*
     - Actionable prompt: *"Search the live web via Tavily? (Consumes 1 credit)"*
     - Primary button: `[Search Web & Answer]` (slanted `<NeoButton>`).

---

### 3. Screen Requirements & Information Architecture

#### Screen A: Dashboard (`/dashboard`)
- **Header:** Brand mark ("CONTEXTUAL"), Daily Credit Counter ("⚡ 8/10"), Theme Toggle (Light/Dark), User Avatar.
- **Notebooks Grid:**
  - 3 columns desktop, 2 columns tablet, 1 column mobile.
  - "Create Notebook" card: Dashed neo-brutalist border, slanted "+ New Notebook" button.
  - Notebook Cards: Title (e.g. "Distributed Systems & Raft Consensus"), creation date, source count badge ("4 sources"), midnight auto-deletion countdown badge, meatball menu (Rename, Delete).

#### Screen B: Desktop Tri-Pane Workspace (`/notebook/[id]` — ≥1280px Viewport)
- **Top Bar:** Breadcrumb (`← Notebooks / Consensus Protocols`), Expiration Banner, Credit Counter, Share (disabled v1), User Profile.
- **Pane 1 (Left 25% width) — Sources & Ingestion:**
  - Header: `Sources (3/10)` + Slanted `+ Add Source` button.
  - List of ingested sources with status badges (e.g. `raft-paper.pdf` [ready], `mit-lecture-youtube` [indexing], `system-docs-web` [ready]).
  - Modal: "Add Source" with 5 tabbed upload options (`Text` | `Web URL` | `PDF Dropzone` | `Transcript (.srt/.vtt)` | `YouTube URL`).
- **Pane 2 (Center 45% width) — Grounded Chat:**
  - Message stream:
    - User prompts in yellow neo-brutalist speech boxes with hard shadow.
    - Assistant responses in crisp markdown typography with inline cyan `[1]`, `[2]` citation pills.
    - Honest refusal card with Tavily web search button example.
  - Composer: Auto-expanding textarea with hard ink border, character/credit check, slanted `Send` button.
- **Pane 3 (Right 30% width) — Original View Showcase:**
  - Empty state: "Click any citation pill in chat to verify proof in the original source."
  - Active state (PDF View): Document header, page jumper (`Page 14 of 28`), high-contrast bounding box highlight over the cited paragraph.
  - Active state (YouTube/Transcript View): Embedded video player at timestamp `18:42` with synchronized autoscrolling transcript dialogue below it, highlighting the cited line.

#### Screen C: Responsive Tablet & Mobile Workspaces
- **Tablet (768px – 1279px):** 2-column split (Chat 50% + Showcase 50%) with a toggle button that opens Sources in a slide-over neo-brutalist drawer.
- **Mobile (320px – 767px):** Single-column tabbed navigation: `[Sources (3)] | [Chat] | [Showcase]`.
  - Tapping an inline citation pill `[1]` in the Chat tab automatically navigates the user to the `Showcase` tab.
  - A sticky floating action button at the bottom center: `← Back to Chat` (slanted neo-brutalist button, z-index 50) immediately returns the user to their exact chat scroll position.
```
